## 📝 Walkthrough Format

Detailed walkthroughs may include:

1. Room overview
2. Reconnaissance
3. Enumeration
4. Vulnerability discovery
5. Initial access
6. Privilege escalation
7. Flags and answers

Commands are presented using code blocks:

```bash
nmap -sC -sV -oN scan.txt TARGET_IP
```

* Direct task answers
* User and root flags

The techniques and tools documented here should only be used:
